# 웹 화면 UI/UX 검토 (2026-10-23)

방법: 실행 중인 화면을 실제로 캡처(데스크톱 1280px, 좁은 화면 420px)하고 `scripts/web/index.html` 코드를 읽어 검토. 대상은 **문항 만들기 탭**, **만든 문항 탭**, 그리고 두 탭이 함께 쓰는 **문항 보기 영역**(학생용/교사용). 사용자가 2번 묶음(A1+A3+A4)과 4번 묶음(C7+B6)을 선택해 **2026-10-23에 변경 완료(✅, 인수인계 4-22)**. 그 뒤 1번 묶음(B1·B2·B3, 4-23)과 3번 묶음(C1·C2·C3, 4-24)도 변경 완료. 나머지는 선택 대기.

표기: 크기 S(몇 줄~1시간) / M(반나절) / L(하루 이상). ★=추천. 근거는 캡처·코드에서 직접 확인한 것.
