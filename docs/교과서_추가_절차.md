# 교과서(출판사) 추가 절차

문항 생성기의 '교과서' 선택 목록은 `data/textbook_registry.json`의 5종이고, **분석이 끝난 책만 선택**할 수 있다.
새 책을 열려면 아래 순서로 분석한다. 모든 명령은 `scripts/textbook` 폴더에서 실행한다.

## 0. 현재 상태 보기 (무료)
```
python pipeline.py status
```
책별로 쪽 분석, 종합, 용어 라벨, 범위, 문체, 원문 전사의 진행 상태와 '선택 가능' 여부가 나온다.

## 1. 계획과 예상 비용 보기 (무료)
```
python pipeline.py plan --book dong_a
```
`--book`은 id(`dong_a`, `mirae_n`, `visang`, `cheonjae_kim_dongjae`, `cheonjae_kim_hwakyung`)나 차례 파일의 이름(`동아`, `천재(김화경)` 등) 모두 가능하다.
천재(김동재) 실측으로 환산한 **1권 전체 약 $15.7**(쪽별 분석 $11 + 서술형·활동·통계 쪽 원문 전사 $4.4 + 용어 라벨 $0.3). 단가는 추정이다.

## 2. 실행 (유료 — 승인 필요)
```
python pipeline.py run --book dong_a --yes
```
`--yes`가 없으면 계획만 보여 주고 멈춘다. 순서는 analyze → aggregate → clean → scope → transcribe → style 이고, 중간에 끊겨도 같은 명령을 다시 실행하면 완료된 쪽은 건너뛰고 이어서 한다. 단계를 골라서 하려면 `--steps analyze,aggregate`처럼 쓴다.

## 3. 선행 조건 (파이프라인이 확인한다)
- `data/textbook_units_math1.json`에 그 책의 **단원 목록과 성취기준 연결**이 있어야 한다. 미래엔은 통계 단원이 차례 쪽에서 확인되지 않아 경고가 나온다(먼저 차례를 정리).
- `docu/`에 그 책의 PDF가 있어야 한다.

## 4. 끝난 뒤
- 서버를 **재시작**하면 교과서 선택 목록에서 그 책이 선택 가능해진다(`실행.bat`을 닫고 다시 실행).
- 새 책이 추가되면 `build_scope.py`가 공통 금지어를 다시 계산한다: 분석된 **어느 책이든** 중1 본문에서 쓰는 말은 금지어에서 빠진다(보수적). 그래서 책이 늘수록 금지어는 줄어들 수 있다.
- '지수 0'처럼 **교과서에서만 근거가 확인된 제한**은, 새 책의 본문에서 그 말이 나오면 `droppedTriggers`로 기록되고 **공통 금지어에서도 빠진다**(어느 책이든 쓰면 막지 않는 보수적 규칙). 그 책이 다루지 않으면 그 책의 `notCovered`에 남는다. 새 책 분석 뒤 `python build_scope.py --book <id>` 출력의 "이 책 본문에 나와 제외" 목록을 확인해 어떤 금지어가 풀렸는지 본다.

## 5. 개별 단계를 직접 실행하려면
| 단계 | 명령 | 비용 |
|---|---|---|
| 쪽별 분석 | `python analyze_book.py --book dong_a` | 유료 |
| 종합 | `python aggregate.py --book dong_a` | 무료 |
| 용어 라벨 | `python clean_terms.py --book dong_a` | 유료 소액 |
| 중1 범위 | `python build_scope.py --book dong_a` | 무료 |
| 원문 전사 | `python transcribe_pages.py --book dong_a` | 유료 |
| 문체·소재 | `python build_style.py --book dong_a` | 무료 |
