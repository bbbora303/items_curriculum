# 수학 서·논술형 문항 구조·과제 패턴 분석 (v0)

분석 대상: 02-2(경기 2025 중등 논술형 길라잡이 수학: 중1 5개 정밀 확인 + 중2·3 5개와 고등 6개는 문항·채점기준표 쪽을 확인), 02-4(서울 초3), 02-5(서울 초6), 01·02-1. `02-3`은 제외.
한계: 02-2의 고등 일부(미적분Ⅱ 일부, 기하)는 확인하지 않음. 02-4·02-5는 텍스트 추출 기준. 수식은 이미지로 확인.

## 1. 문항 한 세트의 구성 (경기형)

1. **평가 개요**: 학교급·학년·과목·영역 / 성취기준과 성취기준별 성취수준(A~E) / 평가 요소(보통 3개) / 수행 과제명 / 평가 유형·배점 / 논술형 평가 제작 의도(소문항별 대상 성취수준 명시)
2. **평가 요소별 수행 수준**: 평가 요소마다 A~E 수준의 수행 서술
3. **수업 계획 및 흐름도**: 차시별 활동, 평가 방법, 수업-평가 연계 주안점 (보통 4~5차시)
4. **평가 문항**: 문항 정보 표(문항번호 / 교과 역량 / 성취기준 / 평가 요소) + 큰 문항 2~4개(소문항 1-1, 1-2…, 소문항별 배점 표기, <조건> 박스, 답안 칸)
5. **채점기준표**: 문항 / 평가 요소 / 채점 요소 / 척도(배점) / 수행 수준
6. **채점 시 유의점 · 예시답안 · 피드백 시 유의점**

서울형(초)은 단계형 문항(수업 중 형성평가) + 서·논술형 문항 + "능숙·보통·도움필요(4·2·0)" 3척도 채점 + 문항별 피드백 구조.

## 2. 국어 설계와 비교 (재사용 가능 여부)

| 항목 | 수학 자료 | 국어 설계와 비교 |
|---|---|---|
| 평가 요소 / 채점 요소 / 수준별 분할 점수 | 있음 (같은 구조) | ✅ 그대로 |
| 소문항 + dependsOn | 있음 (앞 결과를 뒤에서 사용) | ✅ 그대로 |
| 조건(<조건>) | 있음 (문장 수, 사용 용어, 그릴 점 수) | ✅ 수준 서술 방식 유지 |
| 배점 범위 | 10 / 20 / 30점 총점, 소문항 2~8점 | ✅ **결정: 배점 상한 30점** |
| 기본 점수 20% | **없음.** 최하 수준이 0점 또는 1점 | ❓ **국어의 기본 점수 규칙을 수학에도 적용할지 결정 필요** |
| 교과 역량 | 추론, 문제해결, 연결, 의사소통 표기 | 🔧 신규 필드 |
| 풀이 과정 점수 | 결과와 과정을 나누어 채점 요소로 분리 | 🔧 수학 고유 |
| 다양한 풀이 인정 | 예시답안을 둘 이상 제시(방법 A·B), 방법 준수 여부를 수준에 포함하는 사례도 있음 | ✅ **결정: 다양한 풀이 제공.** 🔧 `solutionMethods[]` |
| 단위 채점 | "성취기준이 ~구하기이므로 단위는 평가하지 않음" | 🔧 채점 시 유의점 항목 |
| 사전 협의 필요 사항 | 그래프 점 연결, 눈금 벗어남 등 교사 협의 안내 | ✅ **결정: 교사 확인 사항 명시.** 🔧 `teacherChecks[]`(AI가 제안, 교사 확정) |

## 3. 채점 척도 관찰

- 2점 소문항: **2 / 1 / 0** (정확 / 일부 오류 / 미수행) 또는 2 / 1
- 3~5점 서술: 3 / 2 / 1, 4 / 3 / 2 / 1 등 **4~5단계**, 설명이 논리적 / 일부 오류 / 부분 / 못함 순서
- 8점 문항(소요소 2개): 요소별로 척도 분리 (예: 구하기 6점 + 비교 2점)
- 판단 문항: 5단계(5 / 4 / 3 / 2 / 1), 계산과 판단을 따로 평가
- 공통 표현: "정확하게 / 일부 / 부분적으로 / 오류가 있음 / 어려움이 있음 / 못함"

## 4. 과제 패턴 요약 (23종: 중1 기준 11종 + 중2·3·고 12종)

상세는 `data/task_patterns_math.json`.

중1 11종 상세는 JSON. 아래는 전체 목록.

1. 표 완성 후 관계 서술
2. 공식·성질 일반화 과정 서술
3. 실생활 맥락 계산 + 비교·공정성 판단
4. 주장(친구·학생)의 타당성 판단
5. 식 세우기 -> 값 구하기 -> 비교 판단
6. 표 -> 관계식 -> 그래프 -> 해석(다중 표현 변환)
7. 두 학생 방법 비교 -> 선택 적용 -> 확장
8. 읽기 자료 기반 수학적 모델링·설명
9. 개념 설명하기(예 들기) - 초등 중심
10. 계산 과정 서술
11. 계산 비교 후 선택·성찰 글

관찰된 공통 설계 원칙:
- 한 세트 안에서 **쉬운 계산 -> 설명 -> 판단** 순서로 난이도를 올림
- 마지막 소문항은 판단·논술이며 배점이 가장 큼
- 앞 소문항의 결과를 뒤 소문항이 사용해 연결성을 확보
- 그림·표·그래프가 문항 본문의 일부

## 5. 수학 생성 설계에 주는 시사점

1. **문항 정보 표**의 교과 역량, 성취기준, 평가 요소 연결을 그대로 출력 항목에 넣음
2. 패턴별로 **수치 구조 명세**(변수 범위, 정답 공식, 조건)를 정의하면 코드 후보 생성이 가능한 패턴이 11개 중 8개 이상
3. 패턴 2(공식 유도)와 9(개념 설명)는 숫자가 아니라 **식·서술 검증**이 핵심이라 별도 검증 방식 필요
4. 패턴 4(주장 판단)는 코드가 **참·거짓을 미리 정하고** 수치를 맞추는 방식이 자연스러움
5. 예시답안은 방법이 여럿일 수 있으므로 **방법별 예시답안 + 채점기준에서 "어느 방법이든" 문구**를 생성
6. 소문항 배점 합과 총점 일치, 소문항별 대상 성취수준 명시 규칙은 검증기 규칙으로 추가

12. 규칙 적용 -> 새 규칙 만들기 -> 비교(중2)
13. 지정된 풀이 방법으로 풀기(중2)
14. 읽기 자료의 공식에 값 대입 -> 주장 검증(중3)
15. 그래프 읽기 -> 식 구하기 -> 판단 -> 변형 적용(중3)
16. 열린 구성 + 방법 효율 비교(중3)
17. 증명 빈칸 채우기 + 글쓰기 상황(고)
18. 개념 판별 + 표 완성 + 조건 맞춰 사례 만들기(고)
19. 경우의 수 계산 + 전략 논술(고)
20. 조건에서 그래프 개형 그리기 + 이유(고)
21. 후보를 공식으로 비교해 선택(고)
22. 단계별 식 유도 사슬(고)
23. 주어진 용어를 사용한 설명 + 그래프(고)

(번호 12~23은 JSON의 `level` 필드로 학교급 구분. 중1 시험에서는 1~11번과 일부 응용(15, 18, 19, 20, 22번)을 쓰고, 나머지는 후속 학년용으로 보관)
