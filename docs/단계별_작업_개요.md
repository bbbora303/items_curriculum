## 1단계. 기획·범위 설정

**목적**: 국어 도구를 수학으로 바꿀 때 달라지는 점을 정리하고, 범위와 방향을 정한다.

**주요 작업**
- 국어 `설계_결정사항.md`를 참고해 수학에서 고려할 점과 결정할 점을 정리했다.
  - 수식·그림·표가 문항의 일부라는 점(PDF에서 수식이 깨짐)
  - 코드로 정답을 검산할 수 있다는 점
  - 과정 중심 분할 점수, 다양한 풀이, 단위 채점 여부
  - 계산만으로 끝나 서술이 필요 없는 성취기준의 적합도
- 설계 초안(`수학_설계_초안.md`)을 쓰고, 사용자 질의응답으로 아래 항목을 구체화했다.
  - 그림: ① 글만 쓰기 ② 틀(SVG)에 숫자만 채우기 ③ AI가 그림 코드를 자유롭게 작성 → AI가 구조(JSON)를 쓰고 코드가 그림을 그리는 B+ 방식으로 결정(①은 사용자가 거부, ③은 길이·각도 오류와 검증 곤란 때문에 제외)
  - 수식: 화면은 LaTeX(KaTeX 렌더링), 교사가 LaTeX를 직접 입력하지 않음
  - 숫자: 코드가 "답이 깔끔하게 떨어지는" 후보를 만들고 AI는 문장만 씀. AI가 수치 구조 명세(JSON)의 초안을 쓰고 코드가 안전한 해석기로만 실행
  - 내보내기: 1차 PDF, 2차 HWPX(LaTeX→한컴 수식 변환이 핵심)

**산출물**: `docs/수학_설계_초안.md`, 메모리 기록

**결정 (사용자)**: 중1 수학 먼저 / 국어 도구와 별도 프로젝트 / 성취수준 문서의 예시 평가도구는 생성 로직에서 제외 / 천재 교과서는 김동재·김화경을 별도 출판사로 취급 / 위 그림·숫자·내보내기 방식

**한계·미해결**
- 중2·3·초·고 확장은 미착수
- 보관함·공유, 호스팅·계정(교사 5+어드민)·일일 한도, 사실 확인·법적 고지, 품질 평가 세트(회귀 시험)는 수학에서 아직 결정 안 함
- 설계 초안 작성 시점에 읽은 자료는 일부였다(경기 길라잡이 앞부분, 중1 부채꼴 예시, 서울 초3). 이후 2-1에서 보강했다.

**소요 시간·비용**: 실작업 약 29분(5분 기준 8분 ~ 30분 기준 45분) / Claude Code 호출 13회, 출력 약 1.6만 토큰 / API 비용 없음

**주요 작업**

- 교과서 5종(동아, 미래엔, 비상, 천재 2종)의 차례에서 단원·소단원·시작 쪽을 정리하고 성취기준과 연결했다(키워드 자동 연결).
- 동아 교과서 대표 24쪽을 이미지로 보고 그림 유형을 정리했다(17종 → 이후 19종).
- 예시 문항 PDF(02-2 중1·중2·3·고, 02-4 서울 초3, 02-5 서울 초6)에서 문항 구조와 과제 패턴을 추출했다. 이미지 PDF인 02-3은 사용자 요청으로 제외했다.
- 교과서 분석 방식을 정했다. 차례 정리·그림 유형 파악은 API 없이 하고(제가 이 세션에서 직접 이미지 확인), 전 쪽 상세 분석은 필요할 때 API로 한다.

**산출물**: `data/standards.json`, `data/textbook_units_math1.json`, `data/figure_types_math1.json`, `data/task_patterns_math.json`(23종), `docs/문항구조_과제패턴_분석.md`

**한계·미해결**

**소요 시간·비용**: 실작업 약 49분(25~49분) / Claude Code 호출 61회, 출력 약 7.5만 토큰 / API 비용 없음

### 2-2. 교과서 심화 분석 (10-21 ~ 10-22)

**목적**: 교과서가 실제로 무엇을 어떻게 가르치는지 자료로 만들어, 중1 범위 판별과 교과서별 문항 반영의 근거로 쓴다.

**주요 작업**
1. **천재(김동재) 정밀 분석 (10-21)**: 324쪽을 쪽마다 이미지(가로 1100px)+글자층으로 분석했다(글자 위주로 읽고 안 읽히는 쪽만 다시 읽는 방식은 쓰지 않음 — 사용자 결정). 쪽 유형, 정의 용어 231개, 전제 용어 246개, 교과서 서술형 문제 23개, 발문 지시어, 역량 아이콘, 소재, 대영역 도입 6장의 '배울 내용(중2·3)'을 얻었다. 처음 6쪽과 무작위 2쪽을 원본과 대조해 정확함을 확인했다.
2. **분석 자료 정리·검토**: `kind`가 4가지 뜻으로 섞여 있던 것을 `statementType`·`exampleType`·`problemType`·`figureType`·`termLabel`로 나누고 값을 정리했다. "예시·활동·그림을 다 읽었는가"를 검토해 문제는 한 문장 요약일 뿐 원문이 아니고, 표 값은 56%만 기록되고, FUN 코너는 대부분 빠졌고, `notes`에 AI의 계산 오류가 있음을 확인했다. 숫자 결론이 든 `notes` 112쪽과 분류 의심 2건에는 표시만 붙였다(값은 바꾸지 않음).
3. **원문 전사**: 서술형 11쪽·통계 28쪽·탐구활동 49쪽, 총 79쪽을 요약 없이 옮겼다(통계 259쪽 표 값 62개가 모두 보존됨). 한도 도달로 한 번 중단됐다가 이어서 완료했다. 서술형 원문 20개가 확보됐다.

5. **동아 분석 (10-22)**: 쪽 분석 318쪽(배치 8개, 오류 0), 원문 전사 105쪽, 개념 설명 쪽 전사(동아 80쪽·천재 64쪽, 처음 실패한 각 3쪽은 재시도로 해결)를 했다.
