# 수치 구조 명세 (numspec) — 코드가 후보를 만들고 AI는 문장만 쓰는 방식

예시: `data/numspecs/sector_arc_area.json` / 생성기: `scripts/numgen.py` / 안전한 수식 계산: `scripts/mathcheck.py`

## 1. 한 줄 요약
문항 유형마다 "변수 범위, 정답 공식, 깔끔함 조건"을 JSON으로 적어 두면, 코드가 조건을 모두 만족하는 숫자 조합만 골라 준다. AI는 그 숫자로 상황과 문장을 쓰고, 정답은 같은 공식으로 코드가 다시 계산해 검산한다.

## 2. 형식

| 키 | 설명 |
|---|---|
| `variables` | 변수와 후보 값. `range:[최소,최대]`(+`step`) 또는 `values:[...]` |
| `derived` | 파생값 공식(위에서 아래로 순서대로 계산). 예: `arc = 2*pi*r*theta/360` |
| `constraints` | 모두 참이어야 하는 조건. 예: `denom(coef_pi(arc)) == 1` (호의 길이의 π 계수가 정수) |
| `difficulty` | 난이도별 추가 조건(쉬움·보통·어려움) |
| `claimDesign` | 주장 판단 문항에서 거짓(또는 참) 주장을 어떻게 정할지 |
| `taskPatterns`, `standards` | 이 명세를 쓸 수 있는 과제 패턴, 성취기준 |

## 3. 쓸 수 있는 함수
`sqrt, abs, floor, ceil, gcd, lcm, min, max, denom, numer, coef_pi, is_int, is_square, simplify`, 상수 `pi`, 연산 `+ - * / ** %`, 비교, `and/or/not`, `in (…)`.
- `denom(x)`, `numer(x)`: 유리수의 분모·분자
- `coef_pi(x)`: `x = (유리수)×π`일 때 유리수 계수

## 4. 안전 장치
- 파이썬 `eval`을 쓰지 않고, `ast`로 읽어 허용한 노드와 함수만 직접 해석한다.
- `__import__`, `open`, 속성 접근, 큰 지수(24 초과), 0으로 나눔, 너무 긴 식은 차단된다. (시험: `__import__('os')` 등 5건 차단 확인)
- 숫자는 SymPy 정수·유리수로 정확히 계산한다(0.1 같은 소수 오차 없음).
- 조합이 20만 개를 넘으면 중단한다.

## 5. 사용 흐름
1. G1(설계): 성취기준·과제 패턴에 맞는 명세 선택 (없으면 AI가 초안 작성 -> 사람이 검수해 저장)
2. `numgen`: 제약을 만족하는 후보 N개 중 시드로 하나 선택 -> `numberBinding`
3. G2·G3: AI는 숫자와 상황 문장, 채점기준, 예시답안을 작성. 예시답안에는 `checks`(검산 식)를 함께 쓴다.
4. 검증기(M26, M29): 검산 식을 코드로 다시 계산해 일치 확인, 숫자가 명세 제약을 만족하는지 확인

## 6. 현재 한계
- 명세는 유형마다 있어야 한다. 현재 1개(부채꼴). AI 초안 작성 + 사람 검수로 늘린다.
- 숫자가 핵심이 아닌 과제(개념 설명, 공식 유도, 열린 구성)는 명세를 쓰지 않고, 수식·서술 검증이 별도로 필요하다.
- 본문 문장 속 숫자가 `numberBinding`과 같은지는 아직 자동 검사하지 않는다.
