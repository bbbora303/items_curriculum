# 수학 문항 JSON 스키마와 검증 규칙 (math-0.1)

예시: `data/examples/item_example.json` / 검증기: `scripts/validate_item.py` / 시험: `scripts/test_validator.py`

## 1. 구조

```
item
├ schemaVersion, id, level, grade, domain
├ standardCodes[1~3], assessmentContext(지필·수행), responseType(서술형/논술형 제한·확장), taskPattern
├ competencies[1~3] (문제해결·추론·의사소통·연결·정보처리), maxScore(4~30), unitPolicy(평가함/평가하지 않음)
├ intent                    출제 의도 (소문항별 겨냥 성취수준 명시)
├ numberBinding             { specId, values }  수치 구조 명세에서 고른 숫자
├ stimulus                  { text, figures[ {id,type,params,caption} ], tables[] }  수식은 LaTeX
├ subQuestions[]            no(1-1), prompt, answerType, conditions[], maxScore, targetLevels[A~E], dependsOn[]
│   └ evaluationElements[]  text(~하기), standardCodes
│       └ scoringElements[] text, maxScore, levels[ {score, descriptors[]} ], conditionRefs[]
├ solutionMethods[]         { id, name, summary }                 다양한 풀이
├ modelAnswers[]            { subNo, methods[ {methodId, text, checks[ {label, expr, vars, expected} ]} ] }
├ scoringNotes[]            채점 시 유의점 (연쇄 오류, 표현 다름 인정, 단위 등)
├ teacherChecks[]           { id, text, subNos[] }   교사 확인 사항 (AI 제안, 교사 확정)
├ feedbackNotes[], review, generationMeta
```

국어 스키마와의 차이: 기본 점수 없음(최하 수준 1점), 배점 상한 30, 감점 규칙 없음, `solutionMethods`·`teacherChecks`·`checks`(코드 검산)·`figures` 추가.

## 2. 검증 규칙

| 번호 | 내용 | 종류 |
|---|---|---|
| M1~M2 | 성취기준 1~3개, 존재하는 코드 | 오류 |
| M3~M6 | 평가 맥락, 응답 유형, 과제 패턴, 교과 역량, 단위 정책 값 | 오류 |
| M7 | 총점은 4~30의 정수 | 오류 |
| M8~M9 | 소문항 존재, 소문항 배점 합 = 총점 | 오류 |
| M10~M13 | 소문항 번호 형식, 답 유형, dependsOn은 앞 소문항, 대상 성취수준 A~E, 조건 id 중복 없음 | 오류 |
| M14~M15 | 평가 요소·채점 요소 존재, 평가 요소 성취기준은 문항 성취기준의 부분집합 | 오류 |
| M16~M20 | 채점 요소의 수준 2~5개, 점수 엄격히 감소, 최상 = 채점 요소 배점, **최하 = 1점**, 수준 서술 비어 있지 않음 | 오류 |
| M21~M23 | conditionRefs는 해당 소문항의 조건, 모든 조건이 수준 서술에 연결됨 | 오류 |
| M22 | 채점 요소 배점 합 = 소문항 배점 | 오류 |
| M24~M25 | 풀이 방법 정의, 모든 소문항에 예시답안, methodId 유효 | 오류 |
| **M26** | **예시답안의 검산 식(checks)을 코드로 다시 계산해 기대값과 일치** | 오류 |
| M27 | teacherChecks 항목 필수, 가리키는 소문항 존재 | 오류 |
| M28 | 그림 유형이 `figure_types_math1.json`에 있고 params가 있음 | 오류 |
| M29 | numberBinding의 값이 수치 명세의 모든 제약을 만족 | 오류 |
| W1~W6 | 성취기준 학년 불일치, 대상 성취수준 비어 있음, 평가 요소가 '~하기' 아님, **3점 이상 소문항에 풀이 방법 1개뿐**(`singleMethodReason`으로 예외), 교사 확인 사항 비어 있음, 채점 시 유의점 비어 있음 | 경고 |

## 3. 아직 검증하지 않는 것 (후속)
- 문항 본문(stimulus·prompt) 속 숫자가 numberBinding 값과 일치하는지(문장에서 숫자 추출 비교)
- 수식 LaTeX 문법 검사(KaTeX 렌더 가능 여부)
- 그림 params와 본문 수치의 일치(그림 렌더러 작성 후)
- 수준 서술의 표현·난이도 일관성(AI 점검 단계에서 처리)
- 풀이 서술(증명, 설명) 자체의 정확성: 코드 검산이 불가능한 항목은 AI 점검 + 교사 검토
