## 예시답안

- **1-1** (수를 분수 꼴과 부호로 나누어 표로 정리하기): 높이를 재는 기준을 지면(0 m)으로 정한다. 지면보다 높으면 양수, 낮으면 음수로 나타내므로 전망대 바닥은 $+4$ m, 연못 바닥은 $-3$ m이다. 부호 $+$는 기준(지면)보다 높음을, $-$는 기준보다 낮음을 뜻한다.
- **1-1** (수직선 위에 나타내거나 포함 관계 그림으로 분류하기): 수직선에서 지면을 0으로 정하고 위쪽(오른쪽)을 양의 방향으로 잡는다. 전망대 바닥은 0에서 위로 4만큼 떨어진 점이므로 $+4$, 연못 바닥은 0에서 아래로 3만큼 떨어진 점이므로 $-3$이다. 0보다 위쪽의 수는 양수, 아래쪽의 수는 음수이다.
- **1-2** (수를 분수 꼴과 부호로 나누어 표로 정리하기): 먼저 카드 6의 수를 계산하면 $\frac{ 28 }{ 4 } = 7$이므로 정수이다. 여섯 개의 수는 4, -3, 0, $\frac{1}{4}$, $- \frac{7}{5}$, 7이다. 양수: 카드 1, 카드 4, 카드 6 (3개). 음수: 카드 2, 카드 5 (2개). 0인 카드 3은 양수도 음수도 아니다. 정수: 카드 1, 카드 2, 카드 3, 카드 6 (4개). 정수가 아닌 유리수: 카드 4, 카드 5 (2개).
- **1-2** (수직선 위에 나타내거나 포함 관계 그림으로 분류하기): 수직선 위에 여섯 개의 수를 나타낸다. 0의 오른쪽에 있는 수는 카드 1, 카드 4, 카드 6이므로 양수이고, 왼쪽에 있는 수는 카드 2, 카드 5이므로 음수이다. 카드 3은 0이다. 카드 6의 $\frac{ 28 }{ 4 }$은 7과 같은 점이므로 눈금이 정수인 점에 놓인다. 카드 1, 카드 2, 카드 3, 카드 6은 정수이고, 카드 4의 $\frac{1}{4}$과 카드 5의 $- \frac{7}{5}$은 정수와 정수 사이의 점이므로 정수가 아닌 유리수이다. 따라서 정수는 4개, 정수가 아닌 유리수는 2개이다.
- **1-3** (수를 분수 꼴과 부호로 나누어 표로 정리하기): 현우의 말은 옳지 않다. 첫째, 카드 6의 수는 $\frac{ 28 }{ 4 } = 7$로 정수이다. 분수 꼴로 쓰였다고 해서 정수가 아닌 것은 아니다. 둘째, 유리수는 (정수)/(0이 아닌 정수) 꼴로 나타낼 수 있는 수인데, 정수도 분모를 1로 하여 $4 = \frac{ 4 }{1}$, $-3 = \frac{ -3 }{1}$, $0 = \frac{0}{1}$처럼 나타낼 수 있으므로 모두 유리수이다. 즉 정수는 유리수에 포함된다. 따라서 카드 1~6의 수는 모두 유리수이고, 정수 4개와 정수가 아닌 유리수 2개를 합친 6개이다.
- **1-3** (수직선 위에 나타내거나 포함 관계 그림으로 분류하기): 유리수 전체를 큰 원으로 그리면 그 안에 정수 부분과 정수가 아닌 유리수 부분이 들어 있다. 카드 6의 수는 $\frac{ 28 }{ 4 } = 7$이므로 수직선에서 정수 7과 같은 점이고, 정수 부분에 들어간다. 그러므로 정수 부분에는 카드 1, 카드 2, 카드 3, 카드 6이 들어가고, 정수가 아닌 유리수 부분에는 카드 4, 카드 5가 들어간다. 정수 부분도 유리수를 나타내는 큰 원 안에 있으므로 정수는 유리수에 포함된다. 따라서 현우의 말은 옳지 않고, 여섯 장의 카드 모두 유리수이다.
