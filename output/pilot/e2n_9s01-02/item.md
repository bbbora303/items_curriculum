## 평가 문항

지민이는 수학 시간에 두 자연수 $A$, $B$를 각각 소인수분해하여 카드에 다음과 같이 적었다. 두 카드에서 $B$에는 소인수 3이 없다.

$A = 2^{ 1 } \times 3^{ 1 } \times 5^{ 2 }$, $B = 2^{ 2 } \times 5^{ 2 }$

지민이는 두 수를 직접 계산하지 않고, 소인수분해한 결과를 이용하여 $A$와 $B$의 최대공약수와 최소공배수를 구하려고 한다.

**1-1.** 소인수분해한 결과를 이용하여 $A$와 $B$의 최대공약수를 구하시오. 풀이 과정을 함께 쓰시오. [2점]

**1-2.** 1-1에서 최대공약수를 구한 방법을 바탕으로, $A$와 $B$의 최대공약수와 최소공배수를 구할 때 소인수의 지수를 정하는 기준이 서로 다른 이유를 〈조건〉에 맞게 설명하시오. [4점]

> 〈조건〉 소인수 2와 소인수 3을 예로 들어, 최대공약수와 최소공배수에서 각 소인수의 지수를 어떻게 정하는지 쓸 것

> 〈조건〉 '약수'와 '배수'라는 용어를 모두 사용할 것

**1-3.** 현우는 지민이의 두 수 $A$, $B$에 대해 다음과 같이 말했다.

"최대공약수는 $A$와 $B$에 공통으로 들어 있는 소인수만 곱하되 각 소인수의 지수는 큰 쪽을 택하고, 최소공배수는 $A$와 $B$에 들어 있는 모든 소인수를 곱하되 각 소인수의 지수는 작은 쪽을 택하면 돼."

현우의 말이 옳은지 판단하고, 1-1에서 구한 최대공약수와 1-2에서 설명한 기준을 이용하여 〈조건〉에 맞게 그 이유를 서술하시오. [4점]

> 〈조건〉 현우의 방법에 따라 최대공약수와 최소공배수를 각각 구할 것

> 〈조건〉 현우의 방법으로 구한 최대공약수를 1-1에서 구한 최대공약수와 비교할 것

> 〈조건〉 현우의 말에서 잘못된 부분을 소인수의 지수를 정하는 기준과 관련지어 바로잡을 것

## 예시답안

- **1-1** (소인수의 지수를 직접 비교하는 방법): 두 수에 없는 소인수는 지수를 0으로 본다. 소인수 2의 지수는 1와 2 중 작은 쪽인 1, 소인수 3의 지수는 1과 0 중 작은 쪽인 0, 소인수 5의 지수는 2와 2 중 작은 쪽인 2이다. 지수가 0인 소인수는 곱하지 않는 것과 같으므로 최대공약수는 $2^{ 1 } \times 3^{ 0 } \times 5^{ 2 } = 50$이다.
- **1-2** (소인수의 지수를 직접 비교하는 방법): 소인수 2의 지수는 $A$에서 1, $B$에서 2이다. 최대공약수는 작은 쪽인 1를, 최소공배수는 큰 쪽인 2를 택한다. 소인수 3의 지수는 $A$에서 1, $B$에서 0(없으면 0)이다. 최대공약수에서는 작은 쪽 0을, 최소공배수에서는 큰 쪽 1을 택한다. 즉 최대공약수는 두 수에 모두 있는 소인수만 작은 지수로 택하고, 최소공배수는 어느 한 수에라도 있는 소인수를 큰 지수로 택한다. 그 이유는 최대공약수가 두 수의 공통인 약수여야 하므로 어느 수의 지수보다 큰 지수를 가질 수 없고, 최소공배수는 두 수의 공통인 배수여야 하므로 어느 수의 지수보다 작은 지수를 가질 수 없기 때문이다.
- **1-2** (약수·배수의 뜻으로 검증하는 방법): 소인수 2의 지수가 $x$인 수가 $A$와 $B$의 약수이려면 $x \le 1$, $x \le 2$이어야 하므로 가장 큰 $x$는 1이다. 소인수 2의 지수가 $y$인 수가 $A$와 $B$의 배수이려면 $y \ge 1$, $y \ge 2$이어야 하므로 가장 작은 $y$는 2이다. 소인수 3도 약수가 되려면 $x \le 1$, $x \le 0$이므로 가장 큰 $x$는 0이고, 배수가 되려면 $y \ge 1$, $y \ge 0$이므로 가장 작은 $y$는 1이다. 확인하면 최대공약수 50로 $A$를 나눈 몫은 3, $B$를 나눈 몫은 2이고, 최소공배수 300은 $A$의 2배, $B$의 3배이다.
- **1-3** (소인수의 지수를 직접 비교하는 방법): 현우의 방법으로 최대공약수를 구하면 두 수에 공통인 소인수만 택하여 큰 지수를 쓰므로 $2^{ 2 } \times 3^{ 0 } \times 5^{ 2 } = 100$이다(지수가 0인 소인수는 곱하지 않는 것과 같다). 최소공배수는 모든 소인수의 작은 지수를 택하여 $2^{ 1 } \times 3^{ 0 } \times 5^{ 2 } = 50$이다. 1-1에서 구한 최대공약수는 50이므로 현우의 방법으로 구한 100와 다르다. 따라서 현우의 말은 옳지 않다. 1-2에서 설명한 대로 최대공약수는 공통인 소인수의 작은 지수를 택해야 하고, 최소공배수는 모든 소인수의 큰 지수를 택해야 하므로 $2^{ 2 } \times 3^{ 1 } \times 5^{ 2 } = 300$이다. 현우의 최소공배수 50도 올바른 값 300과 다르다. 현우는 두 기준의 지수 선택을 서로 바꾸어 말한 것이다.
- **1-3** (약수·배수의 뜻으로 검증하는 방법): 최대공약수는 두 수의 공약수 중 가장 큰 수이다. 1-1에서 구한 최대공약수가 50이므로, 이보다 큰 100는 $A$와 $B$의 공약수가 될 수 없다. 현우의 최소공배수는 50인데, 이는 $A = 150$보다 작아서 $A$의 배수가 될 수 없으므로 공배수가 아니다. 반면 올바른 최소공배수 300은 $A$의 2배, $B$의 3배로 두 수의 공배수이다. 따라서 현우의 말은 옳지 않다. 공약수는 약수이므로 지수가 두 수의 지수를 넘을 수 없어 작은 지수를 택해야 하고, 공배수는 배수이므로 지수가 두 수의 지수 이상이어야 하여 큰 지수를 택해야 한다. 현우는 이 기준을 서로 바꾸어 말한 것이다.

## 채점 시 유의점
- 수와 식으로 표현한 문제해결 과정이 수학적으로 논리적이면 예시답안과 달라도 정답으로 인정한다. 소인수의 지수를 비교하는 방법과 약수·배수의 뜻으로 검증하는 방법은 모두 인정한다.
- 앞 소문항의 값이 틀렸더라도 그 값을 바탕으로 이후 계산·판단이 논리적이면 해당 수준 점수를 부여한다.
- 표현 방식이 달라도 최대공약수는 작은 지수, 최소공배수는 큰 지수를 택하는 이유가 약수·배수의 뜻과 연결되어 설명되었으면 정답으로 인정한다.
- 오류가 있어도 소인수의 지수를 근거로 한 시도가 보이면 부분 점수를 부여한다.

- 단위: 평가하지 않음

## 피드백 시 유의점
- '최대공약수니까 큰 지수, 최소공배수니까 작은 지수'라고 이름에 이끌려 기준을 거꾸로 생각하는 오개념이 있는지 확인한다. 약수는 원래 수를 나눌 수 있어야 하고 배수는 원래 수를 포함해야 한다는 뜻으로 돌아가, 지수의 범위를 부등식으로 정리해 보게 한다.
- 한쪽 수에만 있는 소인수(예: 3)를 최대공약수에 포함하거나 최소공배수에서 빠뜨리는 오류가 있는지 확인한다. 없는 소인수의 지수를 0으로 생각하게 하고, 최대공약수와 최소공배수로 두 수를 각각 나누거나 곱해 보며 나누어떨어지는지 직접 확인하게 한다.
