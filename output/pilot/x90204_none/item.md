## 예시답안

- **1-1** (미지수 항을 좌변으로 모아 푼 뒤 해와 이용 계획 횟수를 비교): 한 달 이용 횟수를 $x$회라 하면 회원 방식의 요금은 $(35000+2000x)$원, 비회원 방식의 요금은 $5500x$원이다. 두 요금이 같아지므로 일차방정식은 $35000+2000x=5500x$이다.
- **1-2** (미지수 항을 좌변으로 모아 푼 뒤 해와 이용 계획 횟수를 비교): 방정식 $35000+2000x=5500x$에서 ① 등식의 양변에서 $5500x$를 빼도 등식이 성립하므로 $35000+2000x-5500x=0$, 즉 $35000-3500x=0$이다. ② 양변에서 $35000$를 빼도 등식이 성립하므로 $-3500x=-35000$이다. ③ 양변을 $-3500$으로 나누어도(0이 아닌 같은 수로 나누어도) 등식이 성립하므로 $x=10$이다. 따라서 해는 $x=10$이다.
- **1-2** (미지수 항을 우변으로 모아 푼 뒤 이용 계획 횟수를 두 요금식에 대입해 비교): 방정식 $35000+2000x=5500x$에서 ① 등식의 양변에서 $2000x$를 빼도 등식이 성립하므로 $35000=5500x-2000x$, 즉 $35000=3500x$이다. ② 양변을 $3500$으로 나누어도(0이 아닌 같은 수로 나누어도) 등식이 성립하므로 $x=10$이다. 따라서 해는 $x=10$이다.
- **1-3** (미지수 항을 좌변으로 모아 푼 뒤 해와 이용 계획 횟수를 비교): 해 $x=10$는 0 이상의 정수이고 최대 이용 가능 횟수 25회 이하이므로 문제의 조건에 맞는다. 즉 한 달에 10회 이용하면 두 방식의 요금이 $55000$원으로 같다. 이용 횟수가 1회 늘 때마다 비회원 방식의 요금은 $5500$원, 회원 방식의 요금은 $2000$원씩 늘어 비회원 방식이 $3500$원씩 더 늘어난다. 지민이의 이용 계획 18회는 10회보다 8회 많으므로 비회원 방식의 요금이 회원 방식보다 $3500\\times 8=28000$원 더 많다. 따라서 회원 방식이 더 유리하다.
- **1-3** (미지수 항을 우변으로 모아 푼 뒤 이용 계획 횟수를 두 요금식에 대입해 비교): 해 $x=10$는 0 이상의 정수이고 최대 이용 가능 횟수 25회 이하이므로 문제의 조건에 맞는다. 지민이의 이용 계획 18회도 같은 범위 안에 있으므로 두 요금식에 대입한다. 회원 방식의 요금은 $35000+2000\\times 18=71000$(원), 비회원 방식의 요금은 $5500\\times 18=99000$(원)이다. 회원 방식의 요금이 $28000$원 더 적으므로 회원 방식이 더 유리하다.
