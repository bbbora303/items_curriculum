## 평가 문항

지민이는 수 카드 두 장을 뽑았다. 카드에 적힌 두 자연수를 각각 $A$, $B$라 하면 $A=252$, $B=60$이다. 지민이는 두 수의 최대공약수와 최소공배수를 소인수분해를 이용하여 구하려고 한다. 현우는 지민이에게 "두 수를 소인수분해한 다음, 두 수에 공통으로 들어 있는 소인수의 지수를 어떻게 고르는지가 핵심이야."라고 말해 주었다.

**1-1.** $A$와 $B$를 각각 소인수분해하고, 이를 이용하여 $A$와 $B$의 최대공약수와 최소공배수를 구하시오. 풀이 과정을 함께 쓰시오. [3점]

**1-2.** 지민이는 두 수의 최대공약수와 최소공배수를 구하는 방법을 다음과 같이 말했다.

"두 수에 공통으로 들어 있는 소인수마다 최대공약수에서는 지수가 큰 쪽을, 최소공배수에서는 지수가 작은 쪽을 택하여 곱하면 돼. 그렇게 구하면 최대공약수는 36, 최소공배수는 12이야."

1-1에서 구한 값과 비교하여 지민이의 말이 옳은지 판단하고, 옳지 않은 부분을 〈조건〉에 맞게 바르게 고쳐 쓰시오. [3점]

> 〈조건〉 지민이가 구한 최대공약수와 최소공배수를 1-1에서 구한 값과 각각 비교하여 쓸 것

> 〈조건〉 공통 소인수 2, 3 각각에 대해 최대공약수와 최소공배수에서 지수를 어떻게 택해야 하는지 소인수별로 쓸 것

**1-3.** 1-2에서 바르게 고친 방법으로 최대공약수와 최소공배수를 구할 수 있는 이유를 〈조건〉에 맞게 설명하시오. [4점]

> 〈조건〉 설명에 '약수'와 '배수'라는 용어를 모두 사용할 것

> 〈조건〉 공통 소인수 3를 예로 들어, 최대공약수와 최소공배수에서 3의 지수를 택하는 기준을 각각 쓸 것

## 예시답안

- **1-1** (소인수분해 결과의 지수 비교): 252과 60를 소인수분해하면 $A = 2^{ 2 } \times 3^{ 2 } \times 7^{ 1 } = 252$, $B = 2^{ 2 } \times 3^{ 1 } \times 5^{ 1 } = 60$이다.
두 수에 공통으로 들어 있는 소인수는 2, 3이고, 7은 $A$에만, 5는 $B$에만 들어 있다.
최대공약수는 공통 소인수만 쓰고 지수가 작은 쪽을 택한다. 2의 지수는 2, 2 중 작은 쪽 2, 3의 지수는 2, 1 중 작은 쪽 1이므로 최대공약수는 $2^{ 2 } \times 3^{ 1 } = 12$이다.
최소공배수는 공통 소인수는 지수가 큰 쪽을 택하고(2는 2, 3는 2), 한쪽에만 있는 7과 5는 그 수에서의 지수(1, 1)를 그대로 쓴다. 따라서 최소공배수는 $2^{ 2 } \times 3^{ 2 } \times 7^{ 1 } \times 5^{ 1 } = 1260$이다.
답: 최대공약수 12, 최소공배수 1260
- **1-1** (구한 값이 공약수·공배수 조건을 만족하는지 직접 확인): 먼저 소인수분해하면 $A = 2^{ 2 } \times 3^{ 2 } \times 7^{ 1 } = 252$, $B = 2^{ 2 } \times 3^{ 1 } \times 5^{ 1 } = 60$이다.
후보를 12로 놓고 확인한다. 252÷12 = 21, 60÷12 = 5로 모두 나누어떨어지므로 12는 공약수이다. 두 몫 21와 5에는 공통인 소인수가 없어 12보다 큰 공약수가 없으므로 12는 최대공약수이다.
후보를 1260로 놓고 확인한다. 1260÷252 = 5, 1260÷60 = 21로 모두 나누어떨어지므로 1260은 공배수이다. 두 몫 5와 21에는 공통인 소인수가 없어 더 작은 공배수가 없으므로 1260은 최소공배수이다.
답: 최대공약수 12, 최소공배수 1260
- **1-2** (소인수분해 결과의 지수 비교): 지민이의 방법대로 공통 소인수 2, 3에서 큰 지수를 택하면 $2^{ 2 } \times 3^{ 2 } = 36$이고, 작은 지수를 택하면 $2^{ 2 } \times 3^{ 1 } = 12$이다. 이 값은 1-1에서 구한 최대공약수 12, 최소공배수 1260과 모두 다르므로 지민이의 말은 옳지 않다.
고치면 다음과 같다.
최대공약수: 공통 소인수의 지수를 작은 쪽으로 택한다. 2는 2, 2 중 2, 3는 2, 1 중 1이므로 $2^{ 2 } \times 3^{ 1 } = 12$이다.
최소공배수: 공통 소인수의 지수를 큰 쪽으로 택한다. 2는 2, 3는 2이다. 여기에 한쪽에만 있는 소인수 7, 5를 그 수에서의 지수대로 곱해야 하므로 $2^{ 2 } \times 3^{ 2 } \times 7^{ 1 } \times 5^{ 1 } = 1260$이다.
답: 옳지 않다. 최대공약수는 작은 지수, 최소공배수는 큰 지수를 택하고 한쪽에만 있는 소인수도 포함해야 한다.
- **1-2** (구한 값이 공약수·공배수 조건을 만족하는지 직접 확인): 지민이가 구한 값이 조건을 만족하는지 직접 확인한다.
최소공배수 12는 $A$=252보다 작아서 252의 배수가 될 수 없으므로 공배수가 아니다.
최대공약수 36는 252÷36와 60÷36 중 적어도 하나가 나누어떨어지지 않으므로 공약수가 아니다.
따라서 지민이의 말은 옳지 않다.
고쳐 쓰면, 최대공약수는 공통 소인수의 지수를 작은 쪽으로 택하여 $2^{ 2 } \times 3^{ 1 } = 12$로 하고, 이것은 252과 60를 모두 나누는 가장 큰 수이다. 최소공배수는 공통 소인수의 지수를 큰 쪽으로 택하고 한쪽에만 있는 7, 5도 곱하여 $2^{ 2 } \times 3^{ 2 } \times 7^{ 1 } \times 5^{ 1 } = 1260$로 하고, 이것은 252과 60의 공배수 중 가장 작은 수이다.
답: 옳지 않다.
- **1-3** (소인수분해 결과의 지수 비교): 공통 소인수 3를 예로 든다. $A$에는 3가 지수 2로, $B$에는 지수 1로 들어 있다.
최대공약수: 공약수는 $A$의 약수이면서 $B$의 약수이므로 소인수분해에서 3의 지수가 2 이하이고 1 이하여야 한다. 즉 두 지수 중 작은 쪽 1 이하여야 한다. 최대공약수는 공약수 중 가장 큰 수이므로 3의 지수를 작은 쪽 1로 택한다. 또 $A$에만 있는 7은 $B$의 약수가 아니고 $B$에만 있는 5는 $A$의 약수가 아니므로 공약수에 곱할 수 없다.
최소공배수: 공배수는 $A$의 배수이면서 $B$의 배수이므로 소인수분해에서 3의 지수가 2 이상이고 1 이상이어야 한다. 즉 두 지수 중 큰 쪽 2 이상이어야 한다. 최소공배수는 공배수 중 가장 작은 수이므로 3의 지수를 큰 쪽 2로 택한다. 또 $A$의 배수에는 7이, $B$의 배수에는 5가 반드시 들어 있어야 하므로 한쪽에만 있는 소인수도 모두 곱한다.
- **1-3** (구한 값이 공약수·공배수 조건을 만족하는지 직접 확인): 공통 소인수 3에서 지수를 다르게 택하는 경우와 비교한다.
최대공약수: 3의 지수를 1보다 크게 택한 수는, 3의 지수가 1인 쪽 수의 약수가 될 수 없으므로 공약수가 아니다. 3의 지수를 1보다 작게 택한 수는 공약수이지만, 지수를 1로 택한 공약수의 약수여서 그보다 작다. 따라서 가장 큰 공약수는 지수를 1로 택한 수이다. 예를 들어 $2^{ 2 } \times 3^{ 1 } = 12$는 $A$와 $B$를 모두 나눈다.
최소공배수: 3의 지수를 2보다 작게 택한 수는, 3의 지수가 2인 쪽 수의 배수가 될 수 없으므로 공배수가 아니다. 3의 지수를 2보다 크게 택한 수는 공배수이지만, 지수를 2로 택한 공배수의 배수여서 그보다 크다. 따라서 가장 작은 공배수는 지수를 2로 택한 수이다. 한쪽에만 있는 소인수 7, 5가 빠지면 그 수의 배수가 될 수 없으므로 반드시 곱한다. 예를 들어 $2^{ 2 } \times 3^{ 2 } \times 7^{ 1 } \times 5^{ 1 } = 1260$은 $A$와 $B$의 배수이다.

## 채점 시 유의점
- 수와 식으로 표현한 문제해결 과정이 수학적으로 논리적이면 예시답안과 달라도 정답으로 인정한다. 소인수분해 결과를 표로 정리해도 되며, 한쪽 수에 없는 소인수 칸은 '없음'으로 쓴 경우를 인정한다.
